# 🚑 急救设备寻找APP
<p>这是一个可以在地图上添加急救设备的APP，帮助身边的人，快速拯救特人生命！</p>

## 📱 项目简介

本应用致力于帮助用户在紧急情况下快速定位附近的急救设备，包括：
- 🏥 自动体外除颤器(AED)
- 🎒 急救箱
- 💊 急救 Kit
- 🏥 其他急救设备

## ✨ 主要功能

- 🗺️ 实时地图显示
- 📍 急救设备位置标记
- 🚶 快速导航到设备位置
- 📖 设备使用指南
- 📞 紧急联系人快速拨号
- 🔄 设备状态实时更新

## 💡 技术特点

- 🎯 高精度定位
- 📱 离线地图支持
- ⚡ 实时数据更新
- 👥 用户友好的界面


## 📝 使用说明

1. 📱 打开应用
2. 🔒 允许位置权限
3. 🗺️ 在地图上查看附近的急救设备
4. 👆 点击设备图标查看详细信息
5. 🚶 使用导航功能快速到达设备位置
